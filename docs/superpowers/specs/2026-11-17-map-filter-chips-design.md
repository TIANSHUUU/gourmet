# 地图筛选按钮改版(分类多选 + 国家 → 城市两级)设计

> 2026-11-17,业主提出,指挥官(Opus)整理。实施计划:`docs/superpowers/plans/2026-11-17-map-filter-chips.md`。

## 问题

1. 分类按钮(美食 / 咖啡 / 烘焙 / 酒吧 / 景点 …)默认全部「点亮」并各用分类色,视觉乱;点一下是「去掉该分类」,和直觉相反。
2. 城市按钮把所有城市平铺成一排,城市一多就乱。

## 业主已定的决定

| 问题 | 决定 |
|---|---|
| 分类按钮默认样式 | 全部深灰底白字(`bg-[#1E242C]/80 text-[#F8F2DD]`,与原城市按钮一致) |
| 选中样式 | 橙底白字 `#F0742A` |
| 选择方式 | **可多选**;一个都不选 = 显示全部;再点一次取消 |
| 地图图标颜色 | 不变(徽章、标签照旧用分类色) |
| 城市筛选 | 第一排「总览 + 国家(圆形国旗 + 国名)」;点国家后出现第二排「该国城市」 |
| 点国家时镜头 | 移到刚好框住该国全部地点(和总览一样的俯视,不出小人);再点城市才进城市视角 |
| 国旗画法 | 代码画的圆形国旗(SVG,和分类徽章同一做法,各平台一致);没画的国家先用国旗 emoji 放大裁圆顶上 |

## 交互细节(指挥官定)

- 点「总览」:清空国家与城市,回到全部地点。
- 点未选中的国家:选中它(橙)、清空城市、镜头框住该国地点、展开第二排城市。
- 点已选中的国家:若当前在某个城市里 → 退回该国视角;若已在国家视角 → 取消选择、回总览。
- 点城市:进城市视角(原逻辑不变),国家按钮保持橙色。
- 通过链接 `?city=` / `?place=` 进来、搜索选店、点标签走过去:国家自动跟着城市设好。
- 「只选了国家」这个状态不写进 URL(城市视角照旧写 `?city=`),刷新回总览——够用,以后需要再加。
- 国家清单从 `cities.json` 自动得出(每个城市新增 `country` 字段,ISO 两位码),按首次出现的顺序;中英名在 `src/lib/map/countries.ts` 的 `COUNTRIES`,缺了会有测试报错。

## 不做

- 不改地图上的徽章 / 标签配色;不改首页的分类栏;不改城市视角与小人逻辑。
